 # Tiles Gallery

 This project was completed as a task of Programming Hero. Recently I learned about Next.js, authentication and i had to implement the concepts to buid this project. It was fun.

 ## Technology Used:
 * MongoDB
 * Better Auth
 * Next.js
 * React.js
 * Tailwindcss + daisyUI + HeroUI
 * React-Toastify + React Marquee
 * Javascript(ES6+)
 * JSON
 * Animate.css for animation

 ## Features:
 * Functional Navbar
 * All Tiles page (authentication required)
 * View Tile Details page(authentication required)
 * Register, Log In, Log Out, Update Profile functionality

 Project: [Live Link](https://ph-a08-tiles-gallery.vercel.app/)
